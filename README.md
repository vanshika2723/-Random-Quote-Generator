# ✨ Random Quote Generator

A simple, interactive and responsive **Random Quote Generator** built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🎯 Generates random inspirational quotes
- 👤 Displays quote author
- 🔄 Prevents the same quote from appearing consecutively
- 📱 Fully responsive design
- 🎨 Modern gradient UI
- ✨ Smooth quote transition animation
- 📤 Share Quote functionality
- 📋 Copies quote to clipboard when sharing is unavailable
- 💻 Clean and beginner-friendly code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Share API
- Clipboard API
